# Contributing

Thanks for taking an interest in Donkey Kong 2D. Bug reports, suggestions and pull requests are welcome.

## Reporting a bug

Open an issue with:

- a short description of the problem;
- the steps needed to reproduce it;
- the expected and actual behaviour;
- your operating system and Java version (`java -version`).

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Make your change and keep it focused on a single topic.
3. Compile and run the game locally:
   ```bash
   ./run.sh
   ```
4. Use a clear commit message, preferably in the Conventional Commits style (`fix:`, `feat:`, `docs:`, `refactor:`).
5. Open a pull request describing what changed and why.

## Code style

- Target Java 21.
- Keep the existing package structure and naming conventions.
- Match the indentation and formatting of the surrounding code.
